# Security reporting

Do not place credentials, private source payloads, personal data or exploit details in a public issue or contribution receipt.

Use this repository's **Security → Advisories → Report a vulnerability** control when private reporting is enabled. If that control is unavailable, use an existing verified private contact with an organization maintainer. No security email address or response-time commitment is asserted by this document. For a non-sensitive coordination issue, request a private reporting route without including vulnerability details.

The present repository contains a delivery plan and its validator. Future runtime security controls, incident ownership, privacy handling and operational drills are tracked in the delivery plan. A proposed security control is not an implemented mitigation. The public leaderboard must not count private security reports or expose the content of such reports.
